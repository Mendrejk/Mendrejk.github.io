Privacy policy

This policy describes the owner's private Google Drive backup client, not a public file-sharing or AI service.

Information used

The application uses Google OAuth authorization to connect to the owner's Drive. Its requested scope is https://www.googleapis.com/auth/drive.file, which covers app-created files and files explicitly authorized for the app. It uses the corresponding file metadata and content to store, check, restore and maintain its backup repository.

Selected local files and system data are packaged into Restic backups. Original filenames, filesystem metadata and backup contents are encrypted locally before upload. Google Drive stores the encrypted repository; it does not receive the backup password.

Purpose and sharing

Data is used only to perform backups, integrity checks, restores and owner-directed retention. This backup client does not sell data, use it for advertising, profile users or train AI models. Backup contents are not sent by this client to AI providers or unrelated analytics services.

Google Drive provides the off-site storage. Restic and rclone run on the owner's equipment; these tools are not additional hosted storage services. Authorization credentials are kept privately on the owner's equipment and are not published on this website.

Retention and deletion

The owner controls snapshot retention and deletion. Revoking authorization stops future Drive access but does not automatically delete already uploaded backups. Backups can be removed using the backup tools or Google Drive; Google's own trash and retention rules may also apply.

Control over access

The owner can revoke this application's access through Google Account connections. This is a single-owner application with no public sign-up. For questions or deletion requests, use the support email displayed on the application's Google consent screen.

Google API data

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

These information pages

These static pages do not request Drive access and add no advertising or analytics code. They are hosted on GitHub Pages and served through Cloudflare; those providers may process ordinary web request data under their own policies.
