ai-node Backup

Private system and research backups, controlled by their owner.

ai-node Backup is a personal command-line backup setup using Restic and rclone. It keeps local recovery snapshots and stores an encrypted off-site copy in the owner's Google Drive.

Why Google Drive access is requested

The backup client requests the limited drive.file permission to create, read and manage its own backup files and any files explicitly authorized for this app. It does not request unrestricted access to the entire Drive.

Backup content and original file metadata are encrypted by Restic before upload. The backup password remains under the owner's control and is not sent to Google Drive.

Private use only

This is not a public backup service. There are no customer accounts, public registrations or advertising. These static pages explain the application; they do not initiate Google sign-in or access a visitor's Drive.
